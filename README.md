# OceanBase Obsidian Vault

这是一个面向 OceanBase 学习、实验记录和技术分析的 Obsidian 知识库模板。

## 使用方法

1. 安装并打开 Obsidian。
2. 在启动页选择 **打开文件夹作为仓库**。
3. 选择当前 `OceanBase Obsidian Vault` 文件夹。
4. 打开 [[首页]]，从这里开始。
5. 在 `设置 → 文件与链接` 中，将附件默认位置设置为 `assets`。
6. 在 `设置 → 核心插件` 中启用“模板”“反向链接”“Canvas”和“文件恢复”。

本模板无需社区插件。先坚持使用一段时间，再决定是否增加插件。

## 日常最小工作流

```text
新问题或资料 → 00-收集箱
学习后整理 → 02-OceanBase知识库
执行验证     → 03-实验记录
形成结论     → 04-技术分析报告
完成后归档   → 06-归档
```

## GitHub 建议

将整个 Vault 作为一个 GitHub 私有仓库管理。`assets` 中的图片也必须与 Markdown 一起提交。
